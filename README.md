Intelligent Garment Size Measurement Using Image Processing
⚠️ This project is incomplete and still under development. This is my own original idea and I will keep working on it and adding more features in the future.

About
This project is about measuring garment sizes automatically from images. The basic idea is that instead of using a tape to measure clothes manually, the system will take a photo of the garment and calculate the measurements like length, width, shoulder width and sleeve length on its own using image processing techniques.

Why I Made This
Manual measurement takes time and often gives inconsistent results. In online shopping, wrong sizes are one of the biggest reasons for returns. I thought of building a system that can solve this problem by just analyzing a simple image of the garment.

How It Works
The user uploads a flat lay image of the garment. The system then processes the image, removes the background, detects the edges and important points of the garment, and finally calculates the real world measurements in centimeters or inches.
